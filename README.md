# Traffic Intersection Simulator

Имитационная модель регулируемого перекрёстка на C# / Windows Forms с визуализацией движения в реальном времени и сбором статистики.

## Что это

Дискретная имитационная модель, в которой автомобили и пешеходы появляются на дорогах случайным образом и проезжают перекрёсток, подчиняясь сигналам светофора и правилам приоритета. Модель считает время ожидания и выгружает статистику в текстовый файл.

## Возможности

- **Стохастическая генерация потока.** Начальная скорость автомобиля выбирается случайно из настраиваемого диапазона (по умолчанию 30–120 км/ч), интервал между появлениями машин — тоже случайная величина; от неё зависит плотность потока.
- **Случайное направление проезда** — прямо / налево / направо, определяется в момент появления и подсвечивается цветом.
- **Плавные повороты по кривым Безье** вместо ломаных траекторий.
- **Правила приоритета:** помеха справа, уступка при левом повороте, торможение перед стоп-линией и перед впереди идущей машиной.
- **Пешеходы и пешеходные переходы.**
- **Светофоры** с фазами и переключением.
- **Сбор статистики** — среднее время остановки автомобилей на перекрёстке, выгрузка в `traffic_stats.txt`.
- **Управление из GUI:** минимальная и максимальная скорость, интервал появления, старт / сброс / сохранение статистики.

## Архитектура

| Файл | Ответственность |
|---|---|
| `Program.cs` | Точка входа, запуск WinForms-приложения |
| `MainForm.cs` | Окно, панель параметров, таймер отрисовки (~60 FPS) |
| `Simulation.cs` | Ядро модели: шаг симуляции, спавн, взаимодействие сущностей |
| `Car.cs` | Модель автомобиля: физика движения, траектории, логика приоритетов |
| `Road.cs` | Дороги, полосы, разметка |
| `TrafficLight.cs` | Светофор и его отрисовка |
| `Pedestrian.cs` | Пешеходы |
| `Statistics.cs` | Накопление метрик и выгрузка в файл |

Симуляция использует фиксированный шаг по времени (time-based), что даёт одинаковое поведение независимо от скорости машины, на которой она запущена. Скорости пересчитываются из км/ч в пиксели в секунду.

## Сборка и запуск

Требуется .NET 8 SDK и Windows (проект использует Windows Forms и `System.Drawing`).

```bash
dotnet build
dotnet run
```

Задайте параметры в панели слева, нажмите «Старт». Кнопка сохранения выгружает накопленную статистику в `traffic_stats.txt` рядом с исполняемым файлом.
